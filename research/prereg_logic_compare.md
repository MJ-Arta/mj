## 과제 2: 전략 단위 (보유/현금, 다음 날 종가 체결, 전환마다 0.1% 비용, 현금 수익 0)

| 이름 | 규칙 |
|---|---|
| BH | 계속 보유 |
| MA | 종가 > 200일선이면 보유 |
| MAh | 종가 > 200일선이면 진입, 종가 < 200일선×0.97이면 청산 (이력 의존) |
| BR | 200일선 위 종목 비율 ≥ 60%이면 진입, ≤ 40%이면 청산 |
| MAh∧BR | 둘 다 보유일 때만 보유 |
| MAh∨BR | 둘 중 하나라도 보유면 보유 |
| evC | C 신호에 진입, MAh 청산 조건에 청산, 다음 C까지 대기 |
| evB | B 신호에 진입, MAh 청산 조건에 청산, 다음 B까지 대기 |
| MAh−FED | MAh이되, 연준 인상 국면에는 현금 |
| FXr | 원/달러 < 원/달러 200일선(원화 강세 추세)이면 보유 |

**지표.** 연복리 수익률(CAGR), 연 변동성, 최대 낙폭(MDD), 수익/MDD, 보유 비중, 전환 횟수, 대세상승 구간 포착률(전략 수익 ÷ 보유 수익), 약세 구간 손실 회피.

## 판정 규칙

- **진입 판별 '최선':** 평균 1년 수익과 성공률이 모두 무작위 기준선보다 높아야 합니다(각 p < 0.10). 동시에 대세상승 그룹을 절반 이상 포착해야 합니다. 후보가 9개이므로 본페로니 보정 p(p×9)도 함께 표시합니다.
- **전략 '최선':** 앞 기간과 뒤 기간 모두에서 수익/MDD가 BH보다 높고, 두 기간 순위의 평균이 가장 좋은 것입니다. 한 기간에서만 좋으면 '불안정'으로 표시합니다.
- **결과가 약할 경우:** 어느 것도 기준을 넘지 못하면 "판별 로직 없음"으로 결론 내립니다.
